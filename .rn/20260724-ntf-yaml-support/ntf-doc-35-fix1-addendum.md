## 2. A を採る。ただし2点を修正する

**修正1 ── 「データ行は名前の行の幅に揃え」の句は書かない。**

この事実は同じページに既に2箇所ある。

- `implementation/testdata_notation.rst:658` ── テーブル・``LIST_MAP`` について、
  「``Excel`` 形式では、データ行のセル数がヘッダ行のカラム数より少ない場合、記述しなかった
  カラムには空文字が設定されたものとして扱われる。``YAML`` 形式では、``rows:`` の先頭行のキーの
  一部を後続の行が持たない場合、そのカラムは ``null`` を明示的に指定したのと同じ扱いになる」
- `implementation/testdata_notation.rst:883` ── 可変長ファイルについて、
  「データ行のセル数（Excel形式）または ``rows:`` の各要素の長さ（YAML形式）がフィールド数より
  少ない場合、不足したフィールドは ``""`` として補完される」

**3つ目の言い方を足さない。**同じ事実が別の言い方で複数箇所にある状態が、今回直している
`:1545` と `:883` の不整合そのものである。表に残すのは、この2箇所が書いていない
「宣言されていない値は読み込まない」だけでよい。

**修正2 ── 「カラム名が無い位置のセル」と書かない。**

``YAML`` 形式のテーブル・``LIST_MAP`` は位置ではなくキーで対応する
（`nablarch-testing-yaml@190cc9a` の `YamlSection.java:156`-`:160` が先頭行の `keySet` を
カラム名にし、`YamlTableDataBuilder.java:198`-`:200` が `columnNames` を回して
`rowMap.get(col)` を引く）。「位置」は ``Excel`` 形式にしか当たらないため、両形式に掛ける句には使えない。

`implementation/testdata_notation.rst:1544`-`:1547` を次の4行に置き換える。

```
  * - ファイル・メッセージ
    - フィールド名称の行の行末の空セルを取り除く（\ Excel\ 形式のみ）。フィールド名称が宣言されていない値は読み込まない
  * - テーブル・\ ``LIST_MAP``
    - カラム名の行の行末の空セルを取り除く（\ Excel\ 形式のみ）。カラム名が宣言されていない値は読み込まない
```
