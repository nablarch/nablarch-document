- **解説書は直さない。** 解説書の記述が実装と食い違い、かつ**解説書側が誤っている**と判断した場合は、

  Excel 側に問題があると判断した場合は報告して止める

- **事実には `file:line` と参照コミットハッシュを添える。示せないことは書かず「未確認」と書く**
- **1箇所確認した時点は、まだ根拠ではない。** 具体（文面・条件式・シグネチャ・API 呼び出し）が依存する処理を
  末端まで追う。「その処理が呼ばれている」ことを確認しても、後段で効果が打ち消されていないかは別に確かめる

- **既存のテストが緑であることを、変更が正しい根拠にしない。** 緑は「変更が正しい」証拠にも
  「そのテストが変更を検知していない」証拠にもなる

### 4-1. 論点6 —— 全ての値が Java null の行が YAML でだけ消える
