
============================================
メッセージID及びメッセージ内容の変更手順
============================================

概要
================================================================

アーキタイプから生成したプロジェクトには、ユーザに通知するメッセージID及びメッセージについて、デフォルト設定が用意されている。

これらについては、内容を確認した上で変更する必要がある。

Nablarchにおけるメッセージ管理機能自体については、:doc:`../../libraries/message` を参照


エラー内容とメッセージIDの紐付けの変更方法
==========================================

文字種チェックのエラー内容とメッセージIDの紐付けは、依存ライブラリ(nablarch-main-default-configuration)内のデフォルト設定ファイル
nablarch/core/validation/charset-definition-message-id.config にて行っている。

このファイル中にコメントで「XXXのメッセージID」と記載されている項目が、エラー内容とメッセージIDの紐付けを行っている項目である。

例えば、以下のような記述の場合、errors.zenkakuCharsetがメッセージIDである。

.. code-block:: text

  # 全角文字以外の文字が入力された場合のメッセージID
  nablarch.zenkakuCharset.messageId=errors.zenkakuCharset


環境設定値は、キー値が重複していた場合、後に定義されたものが有効となる。
プロジェクトの環境設定ファイル(src/main/resources/common.properties)はデフォルト設定ファイルより後に読み込まれるため、
以下のように同じキーでプロジェクトのメッセージIDを定義することで、エラー内容とメッセージIDの紐付けを変更することが出来る。

.. code-block:: text

  # 全角文字以外の文字が入力された場合のメッセージID
  # (PJのID体系に併せて設定値を変更)
  nablarch.zenkakuCharset.messageId=M000000017


メッセージIDとメッセージの紐付けの変更方法
==============================================

メッセージIDとメッセージの紐付けは、初期設定ではsrc/main/resources/messages.propertiesで行っている。

このファイルを編集することで、紐付けを変更することが出来る。
