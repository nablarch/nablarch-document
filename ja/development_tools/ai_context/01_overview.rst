============================================
概要と目的
============================================

このツールの目的
============================================

Nablarch開発における生成AI活用の背景
--------------------------------------------

近年、生成AI技術の発展により、ソフトウェア開発の生産性向上が期待されている。
特に、Claude、ChatGPT、GitHub Copilotなどの生成AIツールは、コード生成、リファクタリング、テストコード作成など、さまざまな開発作業を支援できる。

しかし、Nablarchフレームワークは独自のアーキテクチャと設計パターンを持つため、生成AIがNablarchの規約に準拠したコードを生成するには、フレームワーク固有の実装パターンや制約を正確に理解する必要がある。
単にフレームワークのドキュメントを参照するだけでは、生成AIが適切なコードを生成できない場合が多い。

そこで、生成AIにNablarchの実装パターンを正確に伝えるための「コンテキストファイル群」を用意することで、開発者はNablarchの規約に準拠した高品質なコードを効率的に生成できる。

コンテキストファイル群の役割
--------------------------------------------

コンテキストファイル群は、Nablarchフレームワークの技術仕様を生成AIに伝えるためのドキュメント群である。
以下の情報を集約している。

* **実装パターン**: Nablarch特有のクラス設計、メソッド構成、アーキテクチャパターン
* **API使用方法**: フレームワークが提供するユーティリティクラスやアノテーションの正しい使い方
* **制約事項**: 使用できないAPIや実装してはいけないパターン
* **コード例**: 実際に動作する完全なサンプルコード

これらのコンテキストファイルを生成AIツールに読み込ませることで、生成AIはNablarchの規約に準拠したコードを生成できるようになる。

コンテキストファイル群は、以下の4つのレイヤーに分類されている。

1. **共通機能（1_common）**: 全てのアプリケーション種別で共通的に使用する機能
2. **REST API（2_rest）**: REST APIアプリケーションで使用する機能
3. **バッチ処理（3_batch）**: バッチアプリケーションで使用する機能
4. **Webアプリケーション（4_web）**: Webアプリケーションで使用する機能

開発者は、実装するアプリケーション種別に応じて必要なコンテキストファイルを選択し、生成AIツールに読み込ませる。

期待される効果
--------------------------------------------

コンテキストファイル群を活用することで、以下の効果が期待される。

**開発生産性の向上**

* Action、Form、Serviceなどの定型的なクラスを自動生成できる
* 生成AIがNablarchの規約に準拠したコードを生成するため、手戻りが減る
* テストコードやドキュメントの作成も効率化できる

**品質の向上**

* Nablarchのベストプラクティスに基づいたコードが生成される
* フレームワークの制約事項を守ったコードが生成されるため、バグが減る
* コードレビュー時の指摘事項が減り、レビューの質が向上する

**学習コストの削減**

* Nablarchの実装パターンを学習する時間が短縮される
* 実装例を参照しながらコードを生成できるため、初心者でも高品質なコードを書ける
* チーム内でのNablarchの知識共有が促進される


対象読者
============================================

本ガイドは、以下の開発者を対象としている。

* **Nablarchでの開発経験がある開発者**: Nablarchフレームワークの基本的な知識を持ち、Action、Form、Service、UniversalDAOなどの基本的なクラスやAPIを理解している開発者
* **生成AI（Claude、ChatGPT等）を使った開発に興味がある開発者**: 生成AIツールを活用してコード生成やリファクタリングを行い、開発生産性を向上させたい開発者

Nablarchの基本的な知識がない場合は、まず `Nablarchの公式ドキュメント <https://nablarch.github.io/docs/LATEST/doc/>`_ を参照して、フレームワークの基本概念を理解することを推奨する。


前提知識
============================================

本ガイドを活用するには、以下の知識が必要である。

Nablarchフレームワークの基本知識
--------------------------------------------

以下のNablarchの基本的な概念と実装パターンを理解していること。

* **アーキテクチャパターン**: Action → Service → DAO の3層アーキテクチャ
* **主要なクラスとAPI**:

  * UniversalDAO: データベースアクセスAPI
  * BeanUtil/EntityUtil: オブジェクト変換ユーティリティ
  * Bean Validation: 入力値検証フレームワーク
  * JAX-RS（REST API開発の場合）
  * JSPカスタムタグ（Webアプリケーション開発の場合）

* **設定ファイル**: コンポーネント設定ファイル、SQLファイル、メッセージ定義ファイル

詳細は、 `Nablarchアプリケーションフレームワークの解説書 <https://nablarch.github.io/docs/LATEST/doc/application_framework/application_framework/index.html>`_ を参照すること。

生成AIツールの基本操作
--------------------------------------------

以下のいずれかの生成AIツールの基本的な使い方を理解していること。

* **Claude Code**: コマンドラインインターフェース（CLI）で動作するAI開発支援ツール
* **Cursor**: AIアシスタント機能を持つコードエディタ
* **GitHub Copilot**: GitHub提供のAIペアプログラミングツール
* **その他のツール**: Continue、Windsurfなど

これらのツールでは、コンテキストファイルを読み込ませて、生成AIにフレームワークの実装パターンを伝えることができる。
具体的な使い方については、 :ref:`ai_context_basic_usage` を参照すること。
