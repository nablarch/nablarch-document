リクエスト単体テストの設定（MOMによるメッセージング）
=====================================================

.. contents:: 目次
  :depth: 3
  :local:

MOMによるメッセージングのリクエスト単体テストでは、メッセージ受信のテストで、フレームワーク制御ヘッダのフィールド名を既定から変更している場合に、その名前を設定する。テストデータに記述した値に、定型的な変換処理を加えることもできる。変換処理はMOMによるメッセージングに固有の設定ではなく、電文のテストデータを扱うテストで使用する。

使用方法
--------------------------------------------------

フレームワーク制御ヘッダのフィールド名を指定する
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
メッセージ受信のテストで、\ :ref:`フレームワーク制御ヘッダのフィールド名 <testdata_notation-messaging_data>`\ を既定から変更している場合は、環境設定ファイルに\ ``reader.fwHeaderfields``\ を設定し、フィールド名をカンマ区切りで指定する。この設定を使用するのは\ Excel\ 形式のテストデータで、\ YAML\ 形式では\ ``fw_header:``\ に記載したキーがすべてフレームワーク制御ヘッダとして扱われる。

.. code-block:: properties

  # フレームワーク制御ヘッダのフィールド名をカンマ区切りで指定する。
  reader.fwHeaderfields=requestId,addHeader

.. tip::

  同期応答メッセージ送信のテストデータでは、フレームワーク制御ヘッダを専用のデータタイプにフィールドとして記述する。キーと値の組として記述したフレームワーク制御ヘッダは使用されない。

拡張例
--------------------------------------------------

テストデータに変換処理を追加する
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
電文のテストデータに記述した値は、そのまま\ ``text-encoding``\ に指定したエンコーディングでバイト列に変換される。例えば、URLエンコードされたデータが外部システムから連携される場合、URLエンコード済みの値をテストデータに記述することになり、可読性や保守性の面で現実的ではない。テスティングフレームワークは、読み込んだテストデータに定型的な変換処理を加える手段を提供する。

拡張するには\ :java:extdoc:`TestDataConverter <nablarch.test.core.file.TestDataConverter>`\ を実装する。XMLやJSONといったデータの形式ごとに、アーキテクトが実装する。実装するメソッドは次の2つである。

.. list-table::
  :header-rows: 1
  :widths: 35,65

  * - メソッド
    - 実装する内容
  * - ``convertData``
    - テストデータに記述されたデータを、任意の値に変換する
  * - ``createDefinition``
    - 変換後のデータを読み込むためのレイアウト定義を生成する

実装したクラスは、テスト用のコンポーネント設定ファイルに\ ``TestDataConverter_``\ で始まるコンポーネント名で登録する。\ ``TestDataConverter_``\ に続く部分には、テストデータのディレクティブ\ ``file-type``\ に指定した値を使う。

.. code-block:: xml

  <!-- テストデータコンバータ -->
  <component name="TestDataConverter_FormUrlEncoded"
             class="com.example.test.core.file.FormUrlEncodedTestDataConverter"/>

この例では、\ ``file-type``\ に\ ``FormUrlEncoded``\ を指定した電文のテストデータが、登録したコンバータを通してから使用される。URLエンコードを行うコンバータを実装しておけば、テストデータに日本語のまま記述した値が、URLエンコード済みの値を記述した場合と同じように扱われる。

.. tip::

  ``file-type``\ の値は、応答電文のアサート方式にも影響する。電文のテストデータの記述方法とあわせて\ :ref:`メッセージングのデータを記述する <testdata_notation-messaging_data>`\ を参照。
