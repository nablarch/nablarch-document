==========================================
単体テスト実施方法（JUnit 4・既存資産向け)
==========================================

本セクションは、JUnit 4をベースに作成された既存のテスト資産を保守するプロジェクト向けのガイドである。

:ref:`unitTestGuide` の各ページのコード例は、JUnit 5（ :ref:`ntf_junit5_extension` ）を前提とした記述になっている。
JUnit 4で作成された既存のテストコードを保守・追加する場合は、本セクション配下のJUnit 4版のコード例を参照すること。

.. important::

  新規プロジェクトでテストを作成する場合は、JUnit 5を前提とした構成を推奨する。
  :ref:`unitTestGuide` および :ref:`ntf_junit5_extension` を参照すること。

JUnit 4での自動テストフレームワークの利用方法（テストクラスの作成方法や、JUnit 5への移行手順）については、
:ref:`legacy_junit4_testfw_guide` を参照すること。
