テスティングフレームワーク
==================================================
テスティングフレームワークは、JUnitをベースに、Nablarchアプリケーションのテストを補助する機能を提供するフレームワークである。

この解説書は、次の4つで構成する。

:doc:`about/index` では、テストの種類やアーキテクチャなど、導入・設定を行うアーキテクトとテストを実装するアプリケーションプログラマに共通する前提を説明する。役割を問わず、まずこのページを読むこと。

:doc:`setup/index` では、アーキテクトが行う導入と設定を説明する。

:doc:`implementation/index` では、アプリケーションプログラマが行うテストデータの記述とテストコードの実装を説明する。

:doc:`tools/index` では、テスティングフレームワークが提供するツールの使い方を説明する。
