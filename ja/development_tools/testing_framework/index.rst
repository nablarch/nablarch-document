テスティングフレームワーク
==================================================
テスティングフレームワークは、JUnitをベースに、Nablarchアプリケーションのテストを補助する機能を提供するフレームワークである。

.. toctree::
   :maxdepth: 1

   about/index
   setup/index
   implementation/index
   tools/index

テスティングフレームワークの読者は、導入・設定を行うアーキテクトと、テストを実装するアプリケーション開発者の2種類に分かれる。両者に共通する前提を「テスティングフレームワークとは」として独立させているため、最初にこのページを読めば、以降は自分の役割に必要な部分だけを読み進められる。

アーキテクトは「導入と設定」、アプリケーション開発者は「テストの実装方法」を参照する。テスティングフレームワークが提供するツールを使用する場合は、「ツール」から該当ページを参照すればよい。
