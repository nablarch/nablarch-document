テスティングフレームワーク
==================================================
テスティングフレームワークは、JUnitをベースに、Nablarchアプリケーションのテストを補助する機能を提供する
フレームワークである。本章では、テスティングフレームワークの解説書を以下の構成で提供する。

* テスティングフレームワークとは（両読者に共通する前提）
* 導入と設定（アーキテクト向け）
* テストの実装方法（アプリケーション開発者向け）
* ツール（ツールごとの導入と使い方）

テスティングフレームワークの導入・設定を行うアーキテクトは、「テスティングフレームワークとは」と
「導入と設定」を参照する。テストを実装するアプリケーション開発者は、「テスティングフレームワークとは」と
「テストの実装方法」を参照する。テスティングフレームワークが提供するツールを使用する場合は、「ツール」の
該当ページを参照する。
