取引単体テスト（HTTPメッセージング）
==================================================

.. contents:: 目次
  :depth: 3
  :local:

HTTPメッセージングの取引単体テストは、HTTPメッセージ送信を伴うウェブアプリケーションを対象とする。テスティングフレームワークが提供するモックアップクラスに応答電文を返させることで、通信先を用意せずに取引全体が想定どおりに処理されることを検証する。

機能概要
--------------------------------------------------

HTTPメッセージ送信を伴うウェブアプリケーションの取引単体テストでは、テスティングフレームワークが提供するモックアップクラスを使用する。登録方法は\ :ref:`取引単体テストの設定（HTTPメッセージング） <deal_unit_test_setting_http_messaging>`\ を参照。

モックアップクラスが提供する機能は\ :ref:`取引単体テスト（MOMによるメッセージング） <deal_unit_test_mom>`\ と同じである。同ページの説明にある「送信キュー」「受信キュー」は、HTTPメッセージングではいずれも「通信先」と読み替える。

使用方法
--------------------------------------------------

取引単体テストの進め方は、\ :ref:`取引単体テスト（MOMによるメッセージング） <deal_unit_test_mom>`\ の、同期応答メッセージ送信を伴うウェブアプリケーションを対象とする場合と同じである。ただし、テスト結果の確認に使うログは同じではない。HTTPメッセージングでは、要求電文と応答電文が\ ``MESSAGING``\ という名前のロガーに\ INFO\ レベルで出力される。同ページが説明している\ Map\ 形式・\ CSV\ 形式のログは出力されない。ここでは、HTTPメッセージングに固有のテストデータの書き方を説明する。

テストデータを作成する
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
テストデータには、モックアップクラスが返す応答電文のフォーマットとデータを定義する。電文の記述方法は\ :ref:`メッセージングのデータを記述する <testdata_notation-messaging_data>`\ を、テストデータを置くディレクトリの設定は\ :ref:`同期応答メッセージ送信・HTTPメッセージ送信のテストデータの読み込みを設定する <testing_framework_common-send_sync_test_data>`\ を、記述例は\ :ref:`テストデータの記載例 <testdata_examples>`\ を参照。

応答電文は、本文のデータブロック（\ ``RESPONSE_BODY_MESSAGES``\ ）だけを定義すればよい。応答のヘッダを指定する場合は、ヘッダのデータブロック（\ ``RESPONSE_HEADER_MESSAGES``\ ）を併せて定義する。ここに記述したカラムは、そのまま応答電文のヘッダとしてアプリケーションに渡る。

要求電文のデータブロックは定義しない。モックアップクラスは、送信された要求電文をログに出力するときに、テストデータではなくフォーマット定義ファイルを使うためである。要求電文のフォーマットを定義する\ MOM\ によるメッセージングとは、この点が異なる。
